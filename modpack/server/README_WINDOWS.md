# Сервер на двух игроков / LAN

LAN: владелец запускает клиентский профиль и «Открыть для сети» в общем мире. Второй игрок использует идентичные common/server моды и свои клиентские оптимизаторы. Оба имеют личные навыки/исследования; мир/цивилизации общие. Не открывайте игру в публичный Интернет без настройки firewall. Для одной домашней сети используйте локальный адрес и показанный Minecraft порт.

Dedicated: создайте отдельную папку. Установите официальный NeoForge21.1.264 server дляMinecraft1.21.1/Java21; installer загружайте с neoforged.net. Самостоятельно прочитайте/примите EULA, затем штатный run.bat. Скопируйте `server` из server-архива (mods+properties) в эту папку до запуска. user_jvm_args.txt: `-Xms2G -Xmx4G -XX:+UseG1GC` для домашнего сервера на машине владельца; клиент на той же16GB машине сначала4GB, суммарно8GB heap, следите за общей памятью/GC. Клиент6GB + сервер6GB на16GB/Vega7 не рекомендуется без измерений.

online-mode=true сохранён. Не отключайте аутентификацию ради теста. Подключение другого компьютера: локальный IP:25565; необходимые разрешения firewall задаются пользователем. Никаких токенов/RCON в архиве.

server-архив не включает options.txt, renderer/client-only моды или KubeJS client_scripts. Внешние side labels проверяются в lock, не по названию. Общие рецепты/KubeJS server_scripts должны совпадать. FTB Quests пока не установлен; после проверенной версии создайте команду на2игрока, проверьте shared quest completion и личные research/skills отдельно.

Для генерации двумя исследователями: начните с view8/simulation5, измерьте два разных направления. Chunky ставить только проверенный серверный build, pregenerate разумный радиус на новом seed офлайн от игрового теста, с резервной копией и контролем места. Не обещать20TPS без измерений.

Приёмка: два лицензированных клиента → один мир, торговля не выдаёт товар без оплаты, механизмы/магия видны обоим, навыки не объединяются; оба выходят, сервер штатно сохраняется/выключается, повторный вход обоих. Этот сетевой тест ещё не выполнен для полного модпака.
