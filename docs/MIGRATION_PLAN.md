# Переход к личному модпаку

Рабочая ветка `feat/reimagined-modpack-core`, база8e6bab4 (проверенный объединённый кандидат22a4f48 с отчётом). Проверенные remote HEAD: alpha=a9c7423; Freebuff=042fa77; OpenCode=090a2cc; Kilo settlements=29ba004; recovery=c31544c; agents-review=d8af955. Remote alpha уже содержит отдельное объединение ba02b9c/e170654, четыре browser-navigation unit tests и изменённые проверки поселений. Эта работа не перезаписывает/не объединяет его автоматически. Исправление дымаря22a4f48 и совместный GameTest сохраняются в выбранной базе. Статус alpha-профиля не доказывает стабильный TPS.

Инвентаризация исходников: agriculture/barley/orchard/clover; beekeeping; browser adapters (без старого UI); content/creative tabs; cooking; creature/client; engineering+мельница; fishing; magic+исследования+интерфейсы; progression/skills; research/journal; season; settlements/ванильный MerchantMenu; smithing; worldgen. Их регистрации,58предметов, рецепты, модели и старые NBT-ID **сохраняются**. Ничего не удалено ради будущих замен.

| Система сейчас | Решение до проверенного аналога |
|---|---|
| Механизмы/металлургия | сохранить; Create/IE/Mekanism добавлять по одному, старые предметы не переименовывать |
| Навыки/журнал/магия | сохранить данные; Kilo проектирует связь Pufferfish/FTB/magic, без жёсткой линейной блокировки |
| Сезоны/экология/животные/генерация | сохранить; Freebuff проверяет SereneSeasons/Naturalist/worldgen; не удалять старые сущности из сохранений |
| Пчеловодство/ферма/готовка | сохранить; FD/KubeJS унификация только после реестров/тегов/тары |
| NPC/торговля | сохранить серверный MerchantMenu; MCA/GuardVillagers отдельные NPC, запрет клиентских выдач |
| Browser | UI уже удалён; настоящий JEI по официальной версии, optional, без возврата собственного UI |

Первый этап: запуск Core-only, Windows структура/настройки, полный целевой реестр и fail-closed lock; небольшой общий контракт поверх существующих данных, без нового большого фреймворка. Второй: проверенные внешние файлы и зависимости, spark/renderer, реальный клиент/save/restart. Третий: группы контента; все целевые направления остаются. Полную сборку нельзя объявлять рабочей без её фактических файлов и клиента. Не включать guessed KubeJS/config APIs.

Для16GB/Vega7 начальный heap6GB, окно720p,8чанков/simulation5,fast/no-shaders/60FPS; это гипотеза настроек, не измеренный optimum. На cloud Mesa нельзя подтвердить железо пользователя. Прежде удаления старой системы: резервная копия, migration IDs/NBT/recipes, тест на старом и новом мире; запись причины и подтверждение отсутствия потери контента.

Агенты: Kilo — прогрессия/магия/квесты/баланс; Freebuff — мир/экология/цивилизации/измерения. Их ветки не меняются. Сначала используют docs/INTEGRATION_API.md и не меняют bootstrap/API без согласования; готовые коммиты проверяются по фактическим HEAD.
