# Локальная лаборатория магических портов — Windows

Набор не содержит модов, не принимает EULA и не меняет R4. Thaumcraft допускается автором только для личного использования: не загружайте собранные JAR и созданные локальные профили в публичные релизы. Бинарники обоих портов получаются локальной сборкой проверенных ревизий, без обхода лицензий/проверок.

## 1. Подготовка

- Установите Git for Windows с git-scm.com, полный JDK21 (например Temurin), Python3.11+ с Python Launcher (`py`) и Prism Launcher с официальных сайтов.
- Укажите JAVA_HOME на каталог JDK21 и перезапустите PowerShell. Проверки: `git --version`, `py -3 --version`, `& "$env:JAVA_HOME\bin\java.exe" -version`.
- Скачайте **Reimagined-Magic-Ports-Windows.zip**, распакуйте в `C:\Games\MagicLab-Tools`.
- Найдите существующий **собственный CoreJAR** в экземпляре R4: Prism → ПапкаMinecraft → mods → reimagined-0.1.0-alpha.jar. R4 должен быть закрыт. Не передавайте полный каталог Prism или сохранение вместо Core.

## 2. Сборки и подготовка профилей

```powershell
Set-Location C:\Games\MagicLab-Tools
.\Build-MagicLab.ps1 -WorkDirectory C:\Games\Reimagined-MagicLab -CoreJar "C:\PATH\TO\R4\.minecraft\mods\reimagined-0.1.0-alpha.jar"
```

Замените путь кCore. Если Windows блокирует загруженный скрипт, просмотрите его и воспользуйтесь штатным разрешением запуска согласно вашей политике; установщик не отключает ExecutionPolicy. После проверки зависимостей можно вызвать тот же backend напрямую:

```powershell
py -3 magic_lab.py --work C:\Games\Reimagined-MagicLab --core "C:\PATH\TO\R4\.minecraft\mods\reimagined-0.1.0-alpha.jar"
```

Прямой backend также должен запускаться с настроенными Git/Java21/PATH; PowerShell-обёртка выполняет предварительную проверку. Исходники клонируются в `sources`, проверяются origin и точныйcommit изprofile.json. Thaumcraft закреплён наmc/1.21.1, неmain26.3. Не меняются флаги сборки, авторские зависимости и исходники, тесты не отключаются. Gradle скачивает свои официальные зависимости; первый запуск может быть долгим.

Обязательные игровые зависимости разрешаются через официальный ModrinthAPI с проверкой названия, Minecraft1.21.1/NeoForge, зависимостей, размеров и официальныххешей: Thaumcraft — TerraBlender/Curios; Botania — Patchouli. API404/403, неверныйJAR или недостающийmodId останавливают процесс. Новые сторонниеJAR не подменяются mirrors/неизвестными файлами. Простые платформенные диапазоны проверяются локально; окончательная проверка всех Mavenдиапазонов и mixins — NeoForge при запуске.

Логи: `WorkDirectory\logs\<timestamp>\*.log`, затем `artifacts.json` (ревизии, реальныеURL/версии/хеши) и `dependency-audits.json`. При ошибке сборки второго порта лог первого сохраняется. Неисправленные/неполные сборки не объявляются готовыми. Повторная попытка допускает неизменённые исходники и кеш загрузок; существующий экспортпрофиля не перезаписывается. Для новой полной попытки укажите новую WorkDirectory, старую не удаляйте до разбора.

## 3. Prism: поэтапная проверка

После успешного завершения появятся пять ZIP в `WorkDirectory\profiles`:

1. `Thaumcraft-Lab.zip` — порт и обязательные библиотеки.
2. `Botania-Lab.zip` — порт и Patchouli.
3. `Thaumcraft-Core-Lab.zip` — Thaumcraft с Core.
4. `Botania-Core-Lab.zip` — Botania с Core.
5. `Both-Ports-Core-Lab.zip` — оба с Core.

Это **локальные приватные** ZIP для импорта, а не файлы для публикации. Prism → Добавитьсборку → Импорт → выбрать ZIP. Импортируются нативные компоненты Minecraft1.21.1/NeoForge21.1.264; в Versions убедитесь в этих значениях. Выберите Java21, максимум6GB, либо4GB для клиента при отдельномсервере на томже16GBПК. Не запускайте одновременно несколько испытательных клиентов с6GBкаждый. Используйте свой аккаунт; скрипты не получают токены.

Проверяйте в указанном порядке, каждый раз **новый тестовый мир**, не мирR4. Не переносите originalBotania/Thaumcraft рядом с портами: ихmodId конфликтуют. Полный сценарий — RUNTIME_CHECKLIST_RU.md: загрузка/регистрация, исследования и жезлыThaumcraft, маноцепочкаBotania/Patchouli, механикиCore, дваигрока, сохранение/перезапуск и производительность. Проверка JEI/полного48+набора — последующий отдельный экземпляр-копия R4 после минимальных профилей. Здесь никаких квестов портов заранее не добавлено.

## 4. Логи настоящего запуска

Prism сохраняет Minecraftлоги в папке каждого экземпляра. После штатного закрытия:

```powershell
.\Collect-MagicLab.ps1 -WorkDirectory C:\Games\Reimagined-MagicLab -MinecraftDirectory "C:\PATH\TO\LAB\.minecraft" -OutputZip C:\Games\MagicLab-client-report.zip
```

Скрипт использует проверенный коллектор: выбранныеlatest/debug/crashлоги и SHA256списокJAR, безсамихJAR/миров/аккаунтов. Пришлите также соответствующий timestamp-каталог сборочныхлогов иartifacts.json, предварительно просмотрев их; не отправляйте JARпрофилей. Укажите, какой профиль/действие не сработали. Если Minecraft не стартовал иlatest.logнет — сохраните текст консолиPrism вручную.

**Проверено в облаке:** упаковка и логика экспорта на фикстурах. **Не проверено:** исполнение PowerShell наWindows, успешные реальные сборки портов, импорт Prism и игровойклиент/двоеигроков. Ранее обе сборки в облаке блокировались Maven403, поэтому успешный игровойрезультат не заявляется.
