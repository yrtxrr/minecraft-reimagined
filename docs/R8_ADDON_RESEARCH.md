# R8: исследование 20 кандидатов

Первый этап, без установки аддонов. База — неизменённый R7 `c7b140e`, рабочая ветка `feat/reimagined-r8-addons`. Пользователь сообщил о достижении главного меню R7; создание мира, сохранение и два игрока этим не подтверждены.

## Достоверность сведений

Полный структурированный реестр: `pack/r8/addon-research.json`. `source_version_hint` — версия в проверенном исходнике, **не подтверждённый релиз/JAR**. `release_version`, URL файла, дата, SHA-256 и project ID оставлены null, если не проверены. Ни одному кандидату не присвоены VERIFIED_METADATA/RUNTIME_VERIFIED: без официальной публикации, полного набора зависимостей и фактического бинарника это было бы преждевременно. Неполученный guessed Git URL не является доказательством отсутствия проекта.

GitHub Git доступен; API/CDN/Maven ранее систематически возвращали облачный403. Повторные запросы к ним не запускались. Установленные Windows-моды и их lock не доступны здесь. Нет ни одного установленного нового аддона.

## Существенные результаты

- **Mekanism:** проверена именно release/1.21.x, а не main26.3. Все три модуля требуют базовый Mekanism **точно той же полной версии** через `[${file.jarVersion}]`. Исходное10.7.19 не подтверждает суффикс85. ПартиюA можно разрешать только после фактического installed.lock.json.
- **Create Crafts & Additions / Diesel Generators:** исходники собраны вокруг Create6.0.10-280, заявленные диапазоны Create `[6.0.7,6.1.0)`. Это хорошие кандидаты, но не доказательство совместимости опубликованного файла или Create из R7.
- **Enchantment Industry:** Create>=6.0.10, обязательный **Create Dragons Plus>=1.11.9**, NeoForge>=21.1.228. Sable — отдельная **optional** интеграция; нельзя добавлять её как обязательную только из-за compile/dev блока.
- **Aeronautics:** CreateAddition указывает конкретный кандидат `1.3.0+mc1.21.1` и Sable2.0.3; EnchantmentIndustry ссылается на Maven группы `dev.eriksonn.aeronautics`, `dev.simulated_team.simulated`, `dev.ryanhcode.offroad` и официальный для его интеграции `maven.ryanhcode.dev`. Это полезный след, но **косвенный**, не подтверждённый официальный релиз Aeronautics и не проверенная Sable-цепочка. Gadgets & Gizmos/Airliners остаются без надёжно установленной идентичности.
- **Steam ’n’ Rails:** просмотренная ветка1.20/dev для MC1.20.1; даже ветка1.20/create-v6 не означает MC1.21.1. В доступном списке веток нет1.21.1. Это не доказывает отсутствие релиза на другой официальной площадке, поэтому проект DEFERRED, а не объявлен навсегда недоступным.
- **Applied Mekanistics:** источник1.21.1 заявляет AE2 `[19.2.10,20.0.0)`, Mekanism `[10.7.14,11-)`; исходная fallback-версия1.6.0 переопределяется APPMEK_VERSION. Проверять реальные артефакты, а не подставлять эту строку как pin.
- **Extended AE:** выбрана1.21.1-neoforge, main26.1.2 исключён. Нужны AE2>=19.2.8, GuideME, **Glodium** и API WirelessTerminals (часть JarJar); полный closure не подтверждён. Шаблон использует `type="REQUIRED"` в верхнем регистре: существующий Python-аудит сравнивает lowercase-строки, что требует отдельного исправления на R8 перед партиейB. R7 пока не меняется.
- **Expanded Delight:** исходник0.1.4 на1.21.1, но FD build1.21.1-1.2.6 и descriptor1.21-1.2.4 различаются; `neo_version_range` не найден в gradle.properties при наличии placeholder. Не объявлять сборку валидной без реального JAR.
- **My Nether’s Delight:** выбран **Neo-1.21+**, не default1.20.1 backport. Версия исходника1.10.4, FD>=1.3.2. Если R7 имеет более старый FD, не обновлять базу молча — отложить кандидат либо отдельная задача согласования всей партии.
- **MythicBotany:** проверенный upstream4.0 рассчитан на Forge1.20.1 и Botania1.20.1-443-FORGE. Этот исходник несовместим с R8. Совместимый порт1.21.1 и ABI с BotaniaRevived не подтверждены. BotaniaRevived меняет Java-пакеты относительно оригинала и уже включает отдельные заимствованные идеи MythicBotany: это не означает совместимость аддона.
- **Thaumcraft/Botania:** повторно не исследовались с нуля; использованы `docs/MAGIC_PORTS_REVIEW.md`, закреплённые ревизии и MagicLab. Идентичности портов подтверждены, но сборки/клиент заблокированы или не проверены. Магия DEFERRED, Ars Nouveau запрещён.

## Незавершённые проверки идентичности

Slice & Dice, End’s Delight, Ocean’s Delight, Gadgets & Gizmos и Airliners имеют статус UNVERIFIED. Поиск по предполагаемым Git-именам не дал надёжного источника; эти URL не опубликованы как «официальные». Нужен официальный каталог/авторский сайт и сопоставление с source/issue URLs, не случайный одноимённый fork.

## Проверенные источники

Репозитории и точные ревизии записаны для каждого доступного проекта в JSON. Вторичный источник поиска — AllTheMods/ATM-10, MOD_ISSUES.md, подтверждает ссылки на CreateAddition/EnchantmentIndustry; наличие мода уATM не является гарантией совместимости R7. Тексты, конфигурации, ресурсы и код сторонних сборок не копировались.

Дополнительная адресная проверка нового Maven Sable: POM `dev.ryanhcode.sable:sable-neoforge-1.21.1:2.0.3` на maven.ryanhcode.dev/releases вернул403; единственный повтор внепесочницы подтвердил403. Существование/содержимое этого конкретного артефакта не установлены. Новых бинарников не скачано.
