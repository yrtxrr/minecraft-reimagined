# R8: план измерений, без выдуманных результатов

Фактических R8 измерений нет: аддоны не установлены. Нет оснований обещать FPS/TPS на Ryzen5600H/Vega7/16GB. R7 main menu не является benchmark.

## Общие условия

Одинаковые MC/NF/Java, полныйlock, seed, копии мира, настройки видео и расстояния, одинаковые действия двух игроков. Записать CPU/GPU/ОЗУ, версии драйверов/Java, heap, разрешение, view/simulation, списоквключённыхмодов и сценарий. Начальные параметры:720p/Fast/view8/simulation5/безшейдеров;6GB для одного клиента сLAN, либо4GBклиент+4GBdedicated на одном16GBПК. Это бюджетная отправная точка, не измеренный оптимум.

Каждый прогон: запускдо меню/мира,5минпрогрев,10минстабильнойнагрузки, затем исследование новыхчанков в двухнаправлениях. Сравнить R7 и каждуюпартию, не менять условия посередине. Сохранять spark/JFR, FPS/frame-time запись, лог GC и точную ревизию локально, не коммитить миры/сырые профили/аккаунты.

## Сценарии

- A: одинаковые8/32работающие устройства, затем реактор с безопасным штатным управлением; не утверждатьуспехреактора по наличиюcreativeпредмета.
- B: та же AE2 сеть, хранение/автокрафт/перезагрузка и передача Mekanism-ресурсов. Ограниченный объём заданий, записать сетевые/серверные задержки.
- C/D: равное число фабричных линий/кухонь, реальные входы/выходы и запасы; отсутствие дублирования продукции.
- E: сначала малый аппарат без модификаций, затем два игрока на борту, посадка/выход, граница чанка, save/reload. Зафиксировать число блоков/движущихся частей и размер физической сцены. Не делать выводы о слабомGPU по минимальному стенду.
- F: одинаковый масштаб маны/эссенции/исследований без влияния другихмодов; учитывать сохранение и личнуюсинхронизацию.

Метрики: startup seconds, retained/peak heap, CPU/GC, FPS иframe-time, TPS/MSPTp50/p95/p99/max только при реально измеренных квантилях, время генерациичанков и save. Не вычислять1%low по ощущениям. При регрессии изолировать партию и измеренный hotspot, а не отключать её функции ради PASS. Никаких глобальных tick/world scans или принудительнойзагрузкичанков вCore.
