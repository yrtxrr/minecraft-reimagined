# RECIPE_BALANCE.md — Баланс рецептов и устранение дублирования

## Обзор

Баланс рецептов сохраняет уникальность каждого мода и устраняет ненужное дублирование металлов, руд, рецептов, механизмов, энергетических систем и промежуточных компонентов.

## Металлы и руды

| Ресурс | Источник | Обработка |
|--------|----------|-----------|
| Железо | Ванильное | Плавка в печи/доменной печи |
| Медь | Create/IE | Дробление Create, плавка |
| Золото | Ванильное | Плавка, крафт |
| Алмаз | Ванильное | Инструменты, оружие, зачарование |
| Сталь | Vanilla blast furnace + реимagination smithing | Карбюризация железа |

Не добавляем новые виды железа/меди/золота. Каждый мод использует свои ресурсы без замены ванильных.

## Рецепты

- Все существующие рецепты Reimagined Core сохраняются.
- Рецепты модов не удаляются без согласования с Codex.
- Дублирующиеся рецепты скрываются через KubeJS только при полном дублировании функционала.
- Промежуточные компоненты (шестерни, кабели, платы) не дублируются — каждый мод использует свои.

## Механизмы

| Механизм | Мод | Функция | Статус |
|----------|-----|---------|--------|
| Водяное колесо | Reimagined Core | Кинетическая энергия | Реализовано |
| Вал/шестерни | Reimagined Core | Передача вращения | Реализовано |
| Жёрнов | Reimagined Core | Дробление зерна/камня | Реализовано |
| Механическая сеть | Create | Кинетическая автоматизация | Зависит от мода |
| Generators | Immersive Engineering | Kinetic/RF энергия | Зависит от мода |
| Базовые машины | Mekanism | Обработка материалов | Зависит от мода |
| AE2 сеть | Applied Energistics 2 | Хранение, автоматическое crafting | Зависит от мода |
| Компьютеры | CC: Tweaked | Автоматизация, программирование | Зависит от мода |

Не создаём новые механизмы, дублирующие существующие.

## Энергетические системы

Каждая система остаётся уникальной:
- Reimagined Core: кинетическая (вращательная)
- Create: кинетическая (вращательная)
- Immersive Engineering: kinetic + RF
- Mekanism: тепловая/электрическая
- AE2: электрическая (сетевая)

Не создаём общую энергетическую систему.

## Квесты и рецепты

Квесты не блокируют рецепты. Они направляют игрока и дают награды. Не создаём рецепты, которые можно получить только через квесты, если они дублируют существующие.

## Локализация

Названия рецептов, подсказки, описания — в en_us.json и ru_ru.json.

## Статус

Баланс рецептов готов к реализации через KubeJS скрипты и существующие datapack рецепты.
