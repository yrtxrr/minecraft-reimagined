# QUEST_BOOK_DESIGN.md — Квестовая книга FTB Quests

## Обзор

Квестовая книга — основное обучение и прогрессия для одиночного прохождения. Стиль: подробное пошаговое обучение.

Игрок должен понимать:
1. Что он освоил.
2. Что доступно сейчас.
3. Как выполнить следующий шаг.
4. Зачем нужна механика.
5. Как использовать её в дальнейшем.

## 12 глав

1. Первые шаги (Выживание)
2. Живой мир (Биомы, существа, сезоны)
3. Земледелие (Растения, еда, животные)
4. Металлургия (Руды, плавка, сплавы)
5. Механизация (Create: колёса, вал, мельница)
6. Промышленность (Immersive Engineering, Mekanism базовые машины)
7. Цифровая эпоха (AE2, CC: Tweaked)
8. Тауматургия (Thaumcraft: аспекты, аура, инфузия)
9. Магия природы (Botania: мана, рунический алтарь, растения)
10. Цивилизации (Поселения, торговля, репутация)
11. Исследования (Подземелья, боссы, тайны)
12. Иные измерения (Незер, Энд)

## Структура главы

Каждая глава содержит:
- Вводное объяснение (книжная страница).
- Базовые обучающие задания.
- Практические цепочки.
- Продвинутые задачи.
- Награды (знания, опыт навыков, чертежи, репутация, ресурсы).
- Подсказки.
- Связи с другими главами.
- Автоматическую проверку достижений (FTB Quests задачи).

## Правила наград

Разрешены: знания, опыт навыков, чертежи, репутация, небольшие количества ресурсов.

Запрещены:
- Награды, пропускающие целые технологические эпохи.
- Бесконечная выдача ценных ресурсов.
- Обязательные ежедневные задания.
- Случайные награды, разрушающие баланс.

Игрок не должен проходить все направления ради открытия одного.

## Проверка условий

Используем FTB Quests типы задач:
- Item task (получить предмет)
- Advancement task (достижение)
- Location/ biome (посетить место/биом)
- Use item/block (использовать предмет или блок)
- Custom (через Reimagined Core события)

Не проверяем сотни условий каждый тик. Проверка через события.

## Локализация

Все тексты квестов — en_us.json и ru_ru.json под префиксом `quest.reimagined.*`.

Каждое задание содержит: название, описание, цель, инструкцию, подсказку, условие завершения, награду, связь со следующим.

Не создаём невыполнимые квесты. Проверяем реальные рецепты, предметы, события.

## Реализация

KubeJS скрипты для создания квестов (FTB Quests через js квесты) или готовые JSON квесты. Квесты не требуют новых Java-классов.

Сначала реализуется глава 1 как рабочий образец, затем остальные главы добавляются параллельно.

## Связь с рецептами и навыками

Квесты не блокируют рецепты. Они только направляют и дают награды. Навыки дают бонусы, но не запрещают использование инструментов.
