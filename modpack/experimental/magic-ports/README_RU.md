# Отдельный профиль проверки двух конкретных портов

Это изолированный шаблон испытания, **не запускавшийся клиент и не готовый модпак**. R4 и его lock-файл не изменяются. profile.json фиксирует точные проверенные исходники; файлов JAR и выдуманных хешей нет.

## Получение файлов

Официальные страницы авторов:
- https://github.com/notlikethiss/thaumcraft-4-reforged/releases — нужен именно Minecraft1.21.1, не latest26.3. Авторские релизы могут заменяться на месте: запишите имя, исходный URL и SHA256 скачанного файла.
- https://github.com/Velron-Devs/Botania-Revived/releases — именноNeoForge1.21.1, основной игровойJAR, не sources/dev/API/coremod-only.

Наличие опубликованных Release Assets и их работоспособность из облака не подтверждены. Если файла нет, локальная сборка из проверенных исходников (Git, Java21, доступ к официальным Gradle/Maven):

```powershell
git clone https://github.com/notlikethiss/thaumcraft-4-reforged.git Thaumcraft-Lab
Set-Location Thaumcraft-Lab
git checkout --detach dffee19a4f7f82e0538d323d5de403883db1fe0c
.\gradlew.bat build
Set-Location ..
git clone https://github.com/Velron-Devs/Botania-Revived.git Botania-Lab
Set-Location Botania-Lab
git checkout --detach 8da09edaf6bd5ab454899f6306560baf93c79bae
.\gradlew.bat build
```

При ошибке не удалять зависимости/проверки ради сборки. Сохранить полный вывод. Для Thaumcraft локальный путь OpenJDK из properties принадлежит автору; на Windows Java21 должна определяться через JAVA_HOME/Gradle toolchain. Не устанавливайтеJava25/MC26.3 для нашейсборки.

## Создание тестового экземпляра Prism

1. **Добавить сборку → Minecraft1.21.1**, имя `Reimagined Magic Ports Lab`, затем **Редактировать → Версии → Установить NeoForge21.1.264**. Java21, максимум6GB при одномклиенте/4GB при сервере на томже16GBПК, безшейдеров. R4 не редактировать и его сохранения сюда не переносить.
2. В новую **Папку Minecraft** скопировать только собственный CoreJAR из R4 и обязательные зависимости порта. Сначала одинпорт: Thaumcraft+TerraBlender+Curios либо Botania+Patchouli. ТолькоофициальныеNeoForge1.21.1файлы. JEI/Curios уBotania необязательны; для проверкиинтеграции добавлять позже. Не ставить оригинальныеThaumcraft/Botania рядом: modId конфликтует.
3. Проверить минимальныйпрофиль каждого отдельно, затем оба вместе, затем **копию** полногоR4набора в ещёодномэкземпляре с новыммиром. Не открывать старыймир после удаления/замены портов.
4. Оба порта общие: одинаковые игровыеJAR/зависимости у клиента и отдельногосервера. Никогда не приниматьEULA скриптом от именипользователя.

## Приёмка: все пункты пока НЕ ПРОВЕРЕНЫ

- Главное меню, списокмодов: modId thaumcraft/botania, нет duplicate registry/mixin/dependency errors. Создать новыйDefaultмир, выйти/перезапустить.
- Thaumcraft: открытьThaumonomicon, реальныеисследования/аспекты, изготовить и использоватьжезл; выполнитьарканныйрецепт и алхимию/эссенцию; исследоватьновыечанки с генерацией. Результаты не засчитывать по одному наличиюпредметов вcreative.
- Botania: Lexica черезPatchouli; PetalApothecary → generatingflower → spreader → manapool → mana infusion → runicaltar. ПроверитьJEIкатегории после добавленияJEI.
- Core: журнал/личныешколымагии, мельница иNPCторговля продолжаютработать. Не допускатьдублирования предметов или общих личныхисследований.
- Дваигрока: отдельныеисследованияThaumcraft/Core, общийсохранённыймир, согласованноесостояниепулов/жезлов/NPC; выход/смерть/вход, штатнаяостановка/перезапуск. Проверитьне толькоLANхозяина.
- Пятьминутпрогрев+десятьминут: FPS/MSPT/TPS/GC срастущимчисломманамеханизмов/эссенции, генерацияновыхчанков двумяигроками; не объявлять производительность по успешнойсборке.

Записатьверсии/URL/SHA256 всех добавленныхJAR (`Get-FileHash PATH -Algorithm SHA256`), источник/ревизию сборки и условияиспытания. Сборщик `scripts/modpack/collect-diagnostics.py` из R4 можно использовать с --instance новымMinecraftкаталогом; он не изменяетмир. Квесты портов добавляются только после успешного игровогоцикла обоих, не заранее.
