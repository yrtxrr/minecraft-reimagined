# Личный профиль Ryzen5600H / Vega7 /16GB

Цели20TPS и heap6–8GB — не гарантии. Старт: Java21/G1,2–6GB,720p/8чанков/simulation5/fast/60FPS/no shaders. Не применять набор случайных GC-флагов; не писать непроверенные ключи конфигов оптимизаторов.

После доступности файлов: отдельный профиль spark + Embeddium/ModernFix/FerriteCore; затем ImmediateFast/culling/DynamicFPS/Lithium только после проверки точных NeoForge builds и renderer совместимости. Сравнивать один набор изменений за раз, один seed/маршрут/настройки. Culling должен сохранять механические BER, NPC и пчёл. Chunky запускать отдельно по принятому радиусу/дисковому бюджету, не во время измерений, не без согласия EULA.

Для личного клиента достаточно:5мин прогрева+10мин записи обычной игры/новых чанков/поселения/базы; после развития — автоматизация, несколько поселений, Nether/End и60мин сессия. Записывать revision/lock/seed/JVM/resolution, FPS median/1%low, MSPT mean/p95/p99/max и TPS, heap/GC, генерацию и основные CPU-hotspots; мир/записи не вGit. Сохранить и перезапустить между изменениями состава. Потеря save/предметов/оплаты — блокер.

Уже есть честный cloud базис в docs/FINAL_AGENT_INTEGRATION.md: software Mesa,1vs33NPC+пчёлы, event-slice mean3.300/2.184ms,max382/115ms. Это не полныйMSPT/FPS и не Vega7. Длинные паузы остаются неатрибутированными. В этой итерации не заявлять ускорение без нового сопоставимого профиля. spark пока не загружен из-за403.
