# План интеграции R8

## Ворота до первой партии

1. Сохранить снимок исходников R7: выполнено, `pack/r8/r7-source-snapshot.json`. Тег/коммит подтверждены локально и удалённо. Полный установленный состав **не заморожен**, пока отсутствует пользовательский `installed.lock.json`.
2. Получить lock, сверить Create/Mekanism/AE2/FD/FTB/все библиотеки и SHA-256; отдельно проверить Core из настоящего экземпляра Prism. Никаких предположений по старым сообщениям о версиях.
3. Получить конкретные официальные кандидаты и их лицензии/метаданные/хеши. У каждого поля unknown/null должен остаться явный статус. Сначала полное исследование, затем установка.
4. Проверить R7 на новом мире и сделать резервную копию; R7 main menu — только пользовательское свидетельство. Без этого сравнение сохранений/производительности не имеет исходной точки.
5. Исследование выявило 20 статусов, но **нет безопасно зафиксированной партии бинарников**. Установка и изменение рабочего установщика R7 сейчас не разрешаются условиями задания. Это технические ворота, не запрос повторного согласования обычных решений.

После **каждой фактически установленной** партии: отдельный коммит и отчёт, версии/URL/дата/SHA256, зависимости/modId/конфликты, Gradle/JUnit/полныйGameTestServer, графический клиент, новый мир/чанки, рецептыJEI, save/reload, dedicated и два клиента. Невыполненные пункты NOT_TESTED. При критическом конфликте остановить партию, сохранить предыдущий экспорт/lock, не вырезать тесты или функции.

## Будущий установщик R8

Использовать текущие Transport/Resolver/аудит и клиентско-серверный exporter. Канонические подтверждённые версии остаются в pack/mods.json, не заводить конкурирующий ручной менеджер пинов. `pack/r8/addon-research.json` — **не установочный манифест**, не разрешает скачивание. После приёмки переносить проверенные артефакты туда отдельными коммитами с воспроизводимым R8 lock и reuse R7 cache по хешам. Существующие R7 ZIP/манифесты/теги не перезаписывать; собственный новый выпуск получает новый тег.

## Core: архитектурный анализ до миграции

- Колесо/вал/жернов частично перекрываются Create. Пока сохраняются их ID, рецепты и SavedData; будущие альтернативные рецепты/обучение, а не удаление станков из существующего мира.
- Собственные wand/mana/четыре школы/журнал не являются Thaumcraft или Botania. Их namespaces отдельные; позже обсудить отдельную миграцию исследований/ресурсов, не конвертировать автоматически или объединять личные исследования игроков.
- Рыбы, региональная фауна/олень, урожай, растения, пчеловодство сохраняются. «Уникальность» оценивается по поведению и роли, не только по названию вида; Naturalist/кулинарные аддоны могут перекрывать контент, что требует тегов/рецептов, не удаления сущностей.
- Settlement Version2 Settlers+Aggregates/торговля/индивидуальные навыки и мировые сигналы — полезное ядро. Не создавать второй реестр или переписывать систему цивилизаций. Агрегированная экономика не равна физическому городу: не обещать автопостройку.
- Движущиеся пространства Aeronautics могут менять семантику координат/тиков/соседства. Core loaded-only механическая сеть не должна насильно сканировать или загружать такие чанки. Нужны адресные тесты перед любой адаптацией.

Ars Nouveau запрещён, в том числе как автоматически подтянутая обязательная зависимость кандидата. CompileOnly/optional интеграция в чужом source сама по себе не означает обязательную установку мода.

## Сбор недостающих свидетельств на Windows (без установки)

В скачанном исходном ZIP ветки feat/reimagined-r8-addons (не нужно компилировать Core):

```powershell
py -3 scripts/r8/research_addons.py --r7-lock C:\Games\Reimagined-r7\installed.lock.json --output C:\Games\Reimagined-r8-catalog-evidence.json
```

Скрипт только читает lock и официальный API Modrinth для20кандидатов; не загружаетJAR, не меняетprofile/cache/lock и не повышает статусы. Для нерешённых на Modrinth проектов всё равно нужна ручная проверка CurseForge/GitHub/авторских источников. Результат сохраняет сырые зависимости/файлы/хеши каталога, но не подтверждает SHA256 реально скачанногоJAR илиCreateABI. Если output уже существует, укажите новое имя. При недоступности сети причины сохраняются, бесконечныхповторов нет.
