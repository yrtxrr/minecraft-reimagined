## Первая глава FTB Quests — восемь заданий

В Controls найдите действие открытия FTB Quests и назначьте свободную клавишу. Откройте книгу: одна глава, восемь заданий, русские названия/иконки. Для совместного испытания сначала создайте команду через интерфейс FTB Teams и примите приглашение вторым игроком. Проверяйте каждый пункт в Survival; квесты не завершать командами/редактором.

| Задание | Действие | Результат у первого / второго игрока |
|---|---|---|
| Первые шаги | Вручную скрафтить доски или верстак, взять результат | Не проверено |
| Первые инструменты | Вручную скрафтить деревянную кирку | Не проверено |
| Убежище | Поставить кровать и лечь спать | Не проверено |
| Еда и природа | Потратить голод и действительно съесть еду | Не проверено |
| Сезоны и знания | Открыть исследовательский журнал Core правой кнопкой; получение предмета само по себе не должно засчитываться | Не проверено |
| Под землёй | Добыть уголь киркой или железо подходящей киркой; удар рукой не заменяет добычу | Не проверено |
| Первый контакт | Сначала открыть торговлю и закрыть без покупки — не зачёт; затем завершить оплаченную сделку | Не проверено |
| Выбор направления | Явно нажать подтверждение задачи checkmark | Не проверено |

- Каждую награду 25 XP забрать, затем попробовать повторно: повторной выдачи быть не должно. Результат:
- После действия одного игрока команда видит прогресс; личные исследования/навыки другого не открываются от чужого действия. Результат:
- Журнал для диагностического мира при необходимости: `/give @s reimagined:research_journal`; это только выдача предмета, открыть его нужно самому.

## NPC, цивилизации и общие механизмы

Не путать физического NPC с агрегированной экономикой: текущая цивилизация не строит автоматически полноценный город. Это известное ограничение, а не пропавшая генерация.

1. В диагностическом мире создайте поселенца яйцом из вкладки Reimagined (или `/summon reimagined:settler ~ ~ ~`). Проверьте модель/движение/торговое окно.
2. Запишите выбранную сделку и количество предметов до/после. Без оплаты товар не получить. С оплатой списывается именно указанное количество. Второй игрок видит актуальный остаток, товар не удваивается при повторном клике. Результат:
3. `/reimagined settlement list`; при пустом списке только для теста `/reimagined settlement found agricultural Trial`. Повторно не создавайте после перезапуска. Запишите ID, имя, население. Через обычное игровое время проверьте состояние; команда list — для наблюдения. Результат:
4. Оба игрока видят одного и того же NPC и общую цивилизацию. Улей/механизмы отображают общее состояние, мельница не выдаёт двойной результат. Результат:

## Сохранение

Перед обновлением существующего прохождения закрыть игру/сервер и скопировать всю папку мира. Для первого теста используйте новый мир.

Запишите инвентарь обоих игроков, квесты/награды, отдельные исследования, число NPC, ID/население цивилизации и остаток торгового предложения. Один игрок выходит/входит; затем оба сохраняются, хозяин закрывает мир, выходит из Minecraft и запускает его снова. Для dedicated — штатная команда `stop`, затем новый запуск. Проверьте повторный вход обоих.

| Проверка после запуска | Результат |
|---|---|
| Инвентарь и индивидуальный прогресс обоих игроков сохранены | Не проверено |
| Команда и задания FTB сохранены, награды не выдаются повторно | Не проверено |
| NPC и торговля сохранены, нет дубликатов | Не проверено |
| Цивилизация с тем же ID и экономикой сохранена | Не проверено |
| Механизмы продолжают работу без дублирования продукции | Не проверено |
