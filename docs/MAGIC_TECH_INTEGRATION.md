# MAGIC_TECH_INTEGRATION.md — Магиотехнические интеграции

## Обзор

Маготехника — дополнительный путь, не обязательная замена обычной магии и техники. Создаёт уникальные интеграции между технологическими и магическими модами.

## Интеграции

| Интеграция | Описание | Реализация |
|------------|----------|------------|
| Электронный анализатор аспектов | Считывает аспекты предметов из Thaumcraft и выводит данные | KubeJS + серверный скрипт, выход через чат/книгу |
| Автоматизированная алхимическая лаборатория | Связывает Thaumcraft алхимию с Create/ME транспортом | KubeJS рецепты, транспортировка предметов |
| Датчики ауры | Показывают уровень ауры в районе | CC: Tweaked компьютер + скрипт мониторинга |
| Управление механизмами с помощью маны | Botania мана активирует Create/ME устройства | Mana spreader → redox/интерфейс через KubeJS |
| Магическая логистика | AE2 сеть с магическими фильтрами (Thaumcraft аспекты) | KubeJS, AE2 импорт/экспорт с условиями |
| Стабилизация инфузии промышленными устройствами | Create вентиляторы/механизмы стабилизируют инфузию | KubeJS события, редстоун управление |
| Исследования, объединяющие технологию и магию | Квесты, требующие и тех, и магические предметы | FTB Quests, Item task |

## Техническая реализация

- Нет новых Java-классов для магиотехники.
- Все интеграции через KubeJS скрипты, конфиги модов и FTB Quests задачи.
- Реимagination Core события используются только для кастомных условий квестов (по согласованию с Codex).
- Нет сканирования мира каждый тик. Проверка через события использования предметов и блоков.

## Локализация

Все названия интеграций, описания, подсказки — в en_us.json и ru_ru.json под префиксом `magitech.reimagined.*`.

## Статус

Проектирование завершено. Реализация через KubeJS после подтверждения доступности модов Thaumcraft 4: Reforged и Botania Revived.
