# Reimagined Core для личного прохождения вдвоём

Текущая архитектура и бюджеты механик подробно в корневом ARCHITECTURE.md; здесь только новая граница модпака. Один существующий modId `reimagined`, модули продолжают собственные регистрации. Никакого массового удаления/переименования. Полный целевой состав в modpack/mod-registry.json; реальные внешние JAR/версии только из lock.

Используем существующие research/journal, progression/skills, magic и SavedData мира. Малый core API добавляет только ограниченный ledger межмодовых знаний/7независимых эпох и синхронные события. Он не заменяет школы, журнал, рецепты, NPC или их сетевые меню. Интеграции выключаются через COMMON config; отсутствие optional мода не загружает его классы. Нет tick handler/поиска сущностей/чанков/очереди событий у Core.

Для2игроков один authoritative server (integrated LAN либо dedicated NeoForge). Все изменения мира/инвентарей на сервере; research/skills личные. Shared цивилизации — существующий overworld SavedData. FTB team quest sharing зависит от реальной версии и будет отдельно настроен; сейчас FTB не установлен. Клиентские renderer/GUI/оптимизаторы не должны попадать в dedicated профиль. server.properties ограничивает2игрока, view8/simulation5; online-mode сохраняется true. Нет public-server infrastructure.

Не добавляем масштабируемую event database, собственный quest GUI или вторую skill систему. Крупные интеграции решаются config/KubeJS/готовыми модами после проверки реального API. Данные старых миров не трогаются без резервной копии. Внешние JAR пока заблокированы403; Core-only — проверяемый базис, не обещанный полный pack.
