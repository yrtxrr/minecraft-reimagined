# R5: исправление выбора JEI и More Culling

WindowsR4 подтвердил реальные исключающие диапазоны `[1.21,1.21.1)` внутри JAR. Их нельзя исправлять переименованием файла, каталожным тегом или отключением проверки.

R5 проверяет реальные производственныеJAR из официальногоModrinthкаталога приresolve дляJEI/MoreCulling. Требуются правильныеMC/NeoForgeтеги, официальныйразмер/хеш, ожидаемыйmodId и подходящие числовыедиапазоныMC1.21.1/NeoForge21.1.264 внутриJAR, втомчисле вложенныхJarJar. Несовместимыйкандидат остаётся только вcache и не выбирается; выбирается следующий официальныйкандидат в пределах12попыток. HTTP403 и другие сетевыеошибки не запускают перебор. Файлы/метаданные не редактируются.

JEI19.27.0.340 — предпочтительный **кандидат**, поскольку именно его использует проверенный исходникBotaniaRevived1.21.1; это не доказательство совместимости бинарника. Версия выбирается лишь если реально есть в официальномответе и JAR проходит проверку. При отсутствии/несовместимости идёт обычныйограниченныйпоиск. УMoreCulling нет выдуманной заранее провереннойверсии. Официальныепроекты: https://modrinth.com/mod/jei и https://modrinth.com/mod/moreculling; JEI также https://github.com/mezz/JustEnoughItems и https://maven.blamejared.com/mezz/jei/jei-1.21.1-neoforge/ . Новыебинарники в облаке не получены, поэтому ни одна версия не объявляется здесь runtime-проверенной.

Транзитивные зависимости выбранногоJEI также проверяются по реальнымJAR. Точные несовместимые version_id не заменяются произвольно. CFfallback не может обойти проверку. После resolve остаётся общий аудит всего client/server набора перед созданиемпрофиля: две строкиJEI вR4 могут быть проверкой одного файла на обеихсторонах, а не двумякопиями.

## Повторная установка без потери R4

РаспакуйтеR5 вновуюпапку, укажите реальный путь кплану и downloads вашегоR4. Не используйте старыйплан напрямую вinstall.

```powershell
Set-Location C:\Games\Reimagined-Setup-r5
py -3 scripts/modpack/install.py resolve --output C:\Games\Reimagined-r5 --base-plan C:\Games\Reimagined-r4\install-plan.json --reuse-downloads C:\Games\Reimagined-r4\downloads
notepad C:\Games\Reimagined-r5\INSTALL_REPORT.md
py -3 scripts/modpack/install.py install --output C:\Games\Reimagined-r5 --reuse-downloads C:\Games\Reimagined-r4\downloads
```

Перевыбираются толькоJEI/MoreCulling и их зависимости, неиспользуемые другимиартефактами. Общиезависимости остальныхмодов сохраняются; если такая библиотека сама несовместима, процесс остановится, а не обновит её скрытно. Остальные версии/URL/хеши переносятся изbase-plan. Старыефайлы копируются вновыйcache только при совпадении официальногохеша/размера. R4, исходныйcache и миры не изменяются. Для install нужен тотже reuse-downloads, чтобы не скачивать остальныефайлы заново.

Приуспехе импортировать C:\Games\Reimagined-r5\Reimagined-candidate.mrpack вновыйэкземплярPrism. Еслипоиск не нашёл подходящийJAR, это остаётсяunresolved; нельзя объявлятькомплектготовым. Передать INSTALL_REPORT.md/DEPENDENCY_AUDIT.json иошибку. Нольunresolved не заменяет настоящийзапускMinecraft, сохранение идвухигроков.
