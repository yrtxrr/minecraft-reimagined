# Reimagined — личный клиент Windows, первый checkpoint

Это **Core-only**, не полный целевой модпак. Все 40 кандидатов сохранены в mod-registry.json; их официальные метаданные/загрузка заблокированы HTTP403. В архиве только собственный собранный Core, настройки и реестр. Нет Minecraft, NeoForge installer, сторонних JAR, секретов или сохранений. Нет утверждения о проверенном FPS на Vega7.

1. В своём лицензированном лаунчере создайте **отдельный экземпляр** Minecraft1.21.1, установите NeoForge21.1.264 из https://neoforged.net/ (Prism: Edit → Version → Install NeoForge). Java **21 x64**. Это не публичный установщик; согласие EULA даёте самостоятельно.
2. Закройте Minecraft. Скопируйте содержимое каталога `instance` из распакованного архива в папку игры этого экземпляра. Не копируйте поверх единственного сохранения: сделайте резервную копию. Пользовательские миры в архив не входят.
3. Поставьте память min2048/max6144MiB; JVM arguments из jvm-args.txt. Не дублируйте -Xmx, если лаунчер задаёт память отдельно. 8GiB пробуйте только после измерений; 16GiB делятся с Windows и Vega7.
4. Запустите в1280×720, без шейдеров; fast,8чанков, simulation5,60FPS. Проверьте вкладки Reimagined, откройте НОВЫЙ мир. Проверьте журнал, поселенца/оплату/инвентарь, улей. Сохраните, полностью закройте процесс, повторно загрузите мир.
5. Core-only не содержит Embeddium/spark и остальных кандидатов. Для полной сборки нужны официальные версии для **NeoForge1.21.1**, зависимости и фиксация в lock. Fabric/Forge JAR не подходят автоматически. Не добавляйте одновременно BetterEnd и Nullscape. Не переносите тяжёлую генерацию в существующий мир без резервной копии.
6. После установки проверенного spark измерьте10минут обычной игры, новые чанки и поселение: FPS1%low, MSPT p95/p99, TPS, heap/GC. Не меняйте10настроек одновременно. Ограничьте фоновый FPS через проверенный Dynamic FPS после установки; сначала тестируйте обновления по одному.

Повторная сборка архива в репозитории: `python scripts/assemble-modpack.py --profile core-only`. Для полного профиля `--profile full` откажется работать, пока целевые моды/зависимости не проверены и не внесены в lock. Локальные официальные JAR для lock кладут в игнорируемый `modpack/downloads`; скрипт проверяет SHA256, разрешение распространения/личного использования, сторону и точные версии. Он ничего не скачивает и не отключает проверки.
