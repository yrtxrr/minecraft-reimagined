Windows first-run kit for Minecraft1.21.1 / NeoForge21.1.264, personal two-player trial.

Download **Reimagined-Windows-Setup.zip** and **SHA256SUMS.txt** from Assets. You do not need to compile the project. Extract the ZIP, open **START_HERE_RU.md**, and follow the Prism instructions. Core is included; third-party mods are downloaded from official sources on your PC.

This is a **prerelease installer kit, not a runtime-certified full modpack**. A successful release build does not prove Minecraft launch, FTB quests, two-player gameplay or performance. Exact baseline files and unresolved targets are listed in modpack/FIRST_RUN_MODS.md. No EULA has been accepted.

Use scripts/modpack/collect-diagnostics.py and modpack/FIRST_RUN_RESULTS.md to return first-launch results. No later quest chapters have been marked ready.
