# R7 — точная совместимость FML и зависимости конкретных JAR

Основание: расследование2c458b8 и пользовательская выгрузка48записей кэша безошибок. Пользователь подтвердил JEI19.70.0.468, MoreCulling1.0.10 и диапазонMinecraft[1.21,1.21.1). Запуск/совместимостьполногонабора пока не подтверждены.

## Семантика

Обычный numeric_range_contains не ослаблен: диапазон[1.21,1.21.1) по-прежнему исключает1.21.1. Добавлена отдельная platform_range_contains: сначала обычнаяпроверка, затем **только для закреплённых MC1.21.1/NF21.1.264/FML4.0.45** штатные альтернативы mod.minecraft=1.21 иmod.neoforge=21.0.166. В другомконтексте исключение не применяется; неизвестныйсинтаксис остаётсянепроверенным. И выборJAR, и итоговыйаудит используютодинаковуюполитику.

Это воспроизведение конкретного VersionSupportMatrix целевогозагрузчика, не глобальное разрешение старыхмодов. Не доказывает корректностьmixins/API/рецептов/GUI. ДругиеMinecraftдиапазоны продолжают отклоняться.

## Межмодовые зависимости

Аудит читает required/optional/incompatible из реальныхTOML, учитывает сторонуclient/server и проверяет присутствующие версии. Для version=${file.jarVersion} используется Implementation-Version из того жеJARmanifest (без измененияJAR).

- JEI требует mezz_config>=0.6.3 и<1.0.0: отсутствие, неподходящая илинепроверяемаяверсия останавливаютприёмку.
- MoreCulling требует cloth_config>=15.0.0: отсутствие/слишкомстарая/непроверяемаяверсия не пропускаются.
- Sodium[,0.8.0) при наличииSodium является конфликтом:0.7.3отклоняется,0.8.0непопадаетвэтотдиапазон. НеизвестнаяверсияSodium не считаетсябезопасной. ОтсутствиеSodium не ошибка.
- Shareddependencies не обновляются тайно: текущий --base-plan сохраняетнеизменённыеостальныезаписи; если общийнабор несовместим, процесс сообщаетошибку.

Вpreferrred_versionsJEI первойпоставлена подтверждённаяпользователем19.70.0.468; MoreCulling1.0.10 — кандидат для официальнойпроверки. Это не выдуманные version_id/хеши: существование/API/размер/официальныйхеш и реальнаяструктураJAR всё равно проверяются. Диапазоны произвольныхверсий, которые консервативныйпарсер не понимает, не объявляютсяпроверенными; окончательнаяпроверка загрузчика обязательна.

## Хеши и официальный источник

Официальные проекты: ModrinthJEI u6dRKJwZ иMoreCulling51shyZVL. Имена8e70… и36a4… — адреса нашегокэша (SHA256оттекстаконтрольнойсуммы), **не хешисодержимогоJAR**. Присланныхпутей недостаточно, чтобы подтвердить SHA512 содержимого изоблака; реальныефайлы/полныйJSON сюда не загружены.

Transport получает URL/размер/SHA512 либо инойподдерживаемыйофициальныйхеш из API автора. Приreuse-downloads перепроверяет фактическиеполныебайты, а не доверяетимени; испорченныйфайл останавливаетпроцесс. Не редактируются TOML, APIответы, байтыJAR и старыйcache. Проверка подлинности официальнойпубликации выполняется приWindowsresolve/download; не объявлена уже выполненной в облаке.
