## Блокеры

- `kubejs/quests/*.snbt` и `kubejs/startup/*.js` не являются нашими установленными `kubejs/server_scripts`/`startup_scripts` и штатным `config/ftbquests/quests/chapters`. Нет загрузчика этих файлов. Скрипт только пытается получить Java-классы и печатает сообщения; заданий не создаёт.
- Использованы неподтверждённые `ftbquests.quest.QuestFile`, `QuestChapter` и строки `id:"ftbquests:item"`, namespaced quest ID. Нет проверенного экспорта фактической NeoForge1.21.1 версии FTB Quests. В распространённых FTB API пакеты `dev.ftb.mods.ftbquests`, глава содержит список quests, у задач отдельный type и собственный стабильный ID. Нельзя считать этот JSON-подобный SNBT совместимым без загрузки точной версии. Парсинг SNBT/компиляция Java этого не подтверждают.
- Нет listener/адаптера завершения FTB task/team. `mark()` ставит только player NBT boolean; JS его не вызывает и FTB о нём не уведомляет. Совместная команда двух игроков не настроена/не проверена.
- `first_shelter` выдаётся за **разрушение верстака**; `first_craft` ещё и за правый клик по нему. `first_meal` выдаётся за плавку любой вещи, любое зелье, рыбалку и убийство Enemy, не за еду. `first_ore`, `first_trade`, `first_village`, `first_breed` объявлены, но нигде не отмечаются.
- Задания проверяют наличие предметов, а обещают действия: журнал≠открытие/смена сезона, изумруд+хлеб≠успешная торговля, кровать≠сон. «Выбор направления» требует иметь компас и выдаёт ещё компас; настоящего выбора/blueprint нет. XP reward не доказывает выдачу XP собственных навыков.
- `reimagined:research_journal` действительно зарегистрирован в текущем Content; это не блокер. Наличие локализационных ключей не подтверждает их использование FTB и корректность reward types.
- Публичный `mark(player,String)` не ограничивает ключи/количество; повторно записывает одинаковое значение. Clone копирует свой tag (полезно), но не проверен FTB team/личный прогресс после смерти/relogin.
