## Лицензии и личная игра вдвоём

Botania License.md прямо разрешает Use/Share/Adapt и личную игру. При распространении: авторствоVazkii, обозначение изменений, отсутствие платы; также действуют лицензии включённых компонентов. README подтверждает, что VelronDevs не выдаёт свой порт за официальный релиз. Содержимое сторонних компонентов требует собственного лицензионного учёта перед публичной перепаковкой.

Thaumcraft: All Rights Reserved; README содержит «Personal use only», указывает Azanor и оригинальные/decompiled логику/ресурсы, прямо говорит «not intended for redistribution». Это не подтверждение разрешения правообладателя оригинальныхресурсов. Для личного испытания можно следовать описанному автором локальному build, но публичный ZIPReimagined с такимJAR не подготовлен. Для раздачи файла второму игроку безопаснее отдельное получение из авторского источника каждым, а не наша перепубликация; это не снимает вопрос исходных прав.

Никакие ресурсы/код портов не скопированы вCore или GitReimagined. Собранные бинарники не публиковались.

## Изолированный профиль и следующие ворота

Создан `modpack/experimental/magic-ports/profile.json` и README_RU.md: точные ревизии, платформа, зависимости, командыWindowsсборки и отдельный экземплярPrism **Reimagined Magic Ports Lab**. Это шаблон, а не запущенный клиент: файлов для действительного запуска в облаке не получено.

Порядок: каждый порт сCore отдельно → оба вместе → копияR4 с обоими → два игрока → сохранение/перезапуск → профиль нагрузки. Thaumcraft: исследования/жезл/аркана/алхимия; Botania: generatingflower/spreader/pool/infusion/runicaltar/Patchouli/JEI. Проверить личные исследования, общие механизмы и отсутствие дублирования после перезапуска. Никаких реальных игровых пунктов пока не отмеченоPASS.

R4: source-bindings, canonical pins, установщик, Core и квесты оставлены без изменений. Старый статусdeferred-identity вR4 исторический; **идентичности теперь подтверждены**, новые блокеры — недоступные зависимости/непроверенные бинарники/runtime и отдельный вопрос распространенияThaumcraft. Обновление обязательного профиля и квестов отложено до прохождения этих ворот, а не отменено. Не добавлять квесты для ещё неработающей механики.
